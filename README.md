# WP Sender — منصة الربط البرمجي لواتساب

## النشر على Render
1. ارفع المجلد على GitHub ثم أنشئ Web Service: Build `npm install` — Start `npm start`
2. متغيرات البيئة:
   - `JWT_SECRET` (إجباري) قيمة سرية طويلة
   - `ADMIN_EMAIL` بريدك: الحساب المسجل بهذا البريد يصبح مديراً (لوحة الإدارة: `/admin.html`)
   - `SUPPORT_WA` رقم واتساب للدفع والتفعيل (اختياري)
   - `TRIAL_DAYS=2` و `TRIAL_MSGS=30` (الافتراضي)
   - `DATA_DIR=/data` مع Persistent Disk حتى لا تضيع الحسابات وجلسات واتساب
3. سجّل حساباً بالبريد الذي وضعته في ADMIN_EMAIL.

## الاشتراكات
- كل مشترك جديد: تجربة يومان / 30 رسالة (أيهما أسبق).
- بعد انتهائها يتوقف الإرسال حتى تفعّل الاشتراك من لوحة الإدارة (المشتركون ← تفعيل) أو من طلبات الاشتراك.
- الباقات والأسعار تُعدَّل من لوحة الإدارة ← الباقات.
